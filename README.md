# Developer Portfolio Starter

A responsive, minimalist, trilingual portfolio starter built with HTML, CSS, and vanilla JavaScript.

## Included
- English, Hungarian, and Slovak language switcher
- Responsive layout for mobile, tablet, and desktop
- Projects, about, skills, services, and contact sections
- Clear placeholders for contact details and profile links
- Planned projects are explicitly marked as planned

## Run locally
1. Extract the ZIP.
2. Open `index.html` in a browser.
3. Edit the placeholders and content in `index.html` and `script.js`.
4. Adjust colors and layout in `styles.css`.

For a smoother development workflow, open the folder in VS Code and use the Live Server extension if installed.

## Before publishing
- The display name is already set to Puss Kristóf in all three languages.
- Contact details and social links are intentionally hidden until you have real public accounts. Add your email and profile URLs to `index.html` when ready.
- Keep project status labels honest; change them only after projects are implemented.
- Add screenshots and working demo links when available.
- Consider adding a privacy notice if you later add analytics or a contact form.
